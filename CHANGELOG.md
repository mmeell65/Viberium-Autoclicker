# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-11

### Добавлено
- Автокликер мыши: кнопки ЛКМ/ПКМ/СКМ, одинарный/двойной/тройной клик, интервал, случайный разброс, длительность зажатия.
- Позиционирование: за курсором или фиксированная точка с выбором по клику, разброс позиции (jitter).
- Ограничения по количеству кликов и времени, остановка при движении мыши, задержка перед стартом.
- Автокликер клавиатуры с захватом любой клавиши.
- Запись и воспроизведение макросов, библиотека, импорт/экспорт JSON.
- Глобальные горячие клавиши: старт/стоп, удержание для работы, экстренный стоп (F8), X1/X2.
- Целевое окно: работа только в выбранном окне, процесс не сохраняется в профилях.
- Тёмная и светлая темы, кастомная отрисовка интерфейса.
- Русский и английский языки.
- Профили настроек, трей, поверх всех окон, автозапуск с Windows.
- 33 автопроверки в `tools/selftest.py`.
