# Публикация шортсов и тиктоков

Три готовых вертикальных ролика (1080×1920, H.264) в папке `shorts/`.
Рендерятся командой `python tools/make_shorts.py` (нужен ffmpeg в `tools/ffmpeg/`).

| Файл | Хронометраж | О чём |
|---|---|---|
| `viberium-features.mp4` | 22 с | обзор всех функций: кликер мыши, клавиатура, макросы, целевое окно |
| `viberium-keyboard.mp4` | 15 с | кликер клавиатуры и макросы |
| `viberium-free.mp4` | 16 с | бесплатно / без рекламы / open source |

Превью для обложек: `viberium-*-thumb.jpg`.

## Куда публиковать (по убыванию отдачи)

1. **YouTube Shorts** — ссылка в описании работает, монетизация, поиск по Google.
2. **TikTok** — самый большой охват, но ссылка в описании не кликабельная → в описании писать «ссылка в шапке профиля», а в шапке профиля: `github.com/mmeell65/Viberium-Autoclicker`.
3. **VK Клипы** — русская аудитория, ссылка кликабельна.
4. **Telegram-канал** — видео в канал (файл), в конце каждого ролика уже стоит @viberium_autoclicker.

## Правила

- Один и тот же ролик не публиковать в два аккаунта в один день.
- В первые 3 секунды — крупный текст: он уже есть на первом кадре.
- Хэштеги: 5–8, микс из общих и узких.
- Не обещать «взлом игр»: в описаниях только свои задачи и свои устройства.
