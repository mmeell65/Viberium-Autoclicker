# Telegram-канал Viberium

Готовый пакет для запуска канала. Сам канал создаётся вручную в Telegram — здесь лежат все материалы: тексты, изображения и план публикаций.

## Быстрый запуск

1. Откройте Telegram → ☰ → **«Новый канал»**.
2. Название: **Viberium — автокликер для Windows**.
3. Username: `@viberium_autoclicker`. Если занят — выберите вариант из `channel.md`.
4. Описание: скопируйте из `channel.md`.
5. Аватар: загрузите `avatar.png` (512×512).
6. Обложка: настройки канала → «Изменить» → обложка → `banner.png` (1280×640).
7. Опубликуйте и закрепите приветственный пост из `channel.md`.
8. Дальше публикуйте посты из `posts.md` по плану `content-plan.md`.

## Состав пакета

| Файл | Назначение |
|---|---|
| `avatar.png` | Аватар канала, 512×512 |
| `banner.png` | Обложка канала, 1280×640 |
| `channel.md` | Название, username, описание, закреплённый пост, ссылки |
| `posts.md` | 12 готовых постов с текстами и хештегами |
| `content-plan.md` | План публикаций на 4 недели |
| `post-01.png` … `post-06.png` | Промо-карточки для постов |

## Что уже сделано в проекте

- Ссылка на канал добавлена в README и на страницу «Настройки» в приложении.
- Если username придётся изменить, поменяйте его в двух местах:
  - `viberium/config.py` → `TELEGRAM_URL`;
  - `README.md` и `README.en.md` → ссылки на `t.me/...`.

## Рекомендации по оформлению

- Закреплённый пост должен всегда вести на актуальный релиз.
- В каждом посте — одна мысль и один призыв к действию.
- Скриншоты прикладывайте к постам про возможности: так выше охват.
- Не публикуйте больше 1–2 постов в день, чтобы не терять охват.
- Отвечайте на комментарии и собирайте идеи через опросы.
